# Skin v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retrain and honestly evaluate a six-class candidate using audited new cases, then leave the best measured educational API available.

**Architecture:** Add isolated data/training tools under Skin. Reuse preprocessing,
metrics, inference and the shared app. Keep all image/case artifacts in ignored workspaces.

**Tech Stack:** Existing Python, NumPy, Pillow, TensorFlow/Keras, Colab T4, FastAPI.

**Spec:** `docs/superpowers/specs/2026-10-16-skin-v2-design.md`.

## Global Constraints

- Six labels: Acne, Eczema, Psoriasis, Rosacea, Ringworm, Normal.
- Existing API and EXIF/RGB/bilinear 224x224 float32 [0,255] semantics.
- Maximum 120,000,000 original pixels and 10 MiB.
- Never train on frozen audit cases or their detected duplicates.
- Normal is a weak inherited label; no invented clinical verification.
- No test tuning, image/model commits, runtime dependency upgrades or own merge.

## Review Focus

- Different photos of a frozen SCIN case must all be excluded.
- Cross-source exact/near duplicate clusters must not cross train/validation/test.
- Tied/unsupported or low-confidence labels must not enter validation/test.
- Missing Normal test support must not produce a six-class passing gate.
- A worse candidate or invalid export must leave the known active artifact usable.

### Task 1: Audited v2 data protocol

**Files:** `skin/data/prepare_v2.py`, `skin/tests/test_v2.py`.

**Interfaces:** `select_cases(cases, labels, excluded_ids)` returns selected SCIN
case records; `split_cases(records)` returns deterministic case-to-split mapping;
`prepare(args)` creates immutable images, CSV manifests, provenance and exclusions.

- [ ] Add failing tests for complete frozen-case exclusion, tied-label rejection,
  deterministic case grouping and blind-label thresholds. Example fixture:
  `assert select_cases({'held': case}, [label], {'held'}) == []`.
- [ ] Run `python -m pytest skin/tests/test_v2.py -v`; confirm the behavior is absent.
- [ ] Implement original-source and SCIN ingestion with pinned metadata hashes,
  safe downloads, byte/pixel/perceptual grouping and original partition protection.
- [ ] Run focused tests and actual preparation; inspect counts and exclusions.
- [ ] Commit verified data tools, tests and aggregate provenance only.

### Task 2: Fresh training and validation-only selection

**Files:** `skin/training/v2.py`, `skin/tests/test_v2.py`, GPU notebook cells.

**Interfaces:** `domain_selection(labels, logits, sources)` calculates .5 times
each supported-domain macro-F1 (or .4 original/.4 SCIN/.2 verified atlas when
the third source is present); `train(args)` uses frozen v2 manifests and writes
best.keras, history, config and validation logits; `finalize(args)` locks the
checkpoint/calibration and exports the existing runtime artifact contract.

- [ ] Add a hand-checked test showing an original-domain majority cannot hide
  SCIN validation failure: perfect original logits plus always-wrong SCIN logits
  must produce selection score `.5`.
- [ ] Run focused tests and observe RED, implement and verify GREEN.
- [ ] Run the complete shared suite including `-m 'real_model or not real_model'`.
- [ ] Commit/push source, fetch its exact SHA in Colab and train on free T4.
- [ ] Retain checkpoints, select on validation, calibrate on validation and freeze
  the final model SHA. Preserve data/test locks and all predecessor artifacts.

### Task 3: Blind evaluation, delivery and API verification

**Files:** `skin/training/v2.py`, `docs/skin/V2_EVALUATION.md`, local artifact bundle.

- [ ] Apply the spec's predeclared educational promotion rule; never infer a

- [ ] Verify artifact checksum/class order, save rollback and install the selected
